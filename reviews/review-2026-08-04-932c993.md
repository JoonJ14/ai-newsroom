`HEADING_RE` is line-anchored, so `# Install the CLI` inside a ` ```bash ` block is
indistinguishable from an `<h1>`. Two consequences: the comment could win heading
selection, and the section boundary search terminated at the first such comment.

an unterminated code fence containing zero install commands:

| `ggml-org/llama.cpp` | 400 chars, unbalanced | 1201 chars, balanced |

The original 12 ad-hoc tests missed this because they asserted on the heading and the
section length, never on content. Length looked plausible precisely because the
truncation happened partway through.

## Post-fix validation pass

Run against the changes made *during* the review loop, per `/review-pipeline` Step 4.
This caught one defect introduced by a fix — the class DEC-029 predicts for late rounds.

| # | Finding | Severity | Provenance | Resolution |
|---|---|---|---|---|
| 13 | The lone-surrogate guard added for finding 12 also destroyed **valid** entity-encoded surrogate pairs: `&#xD83D;&#xDE00;` decoded correctly to 😀 before the guard and to `""` after | WARN | **cycle-introduced** | Fixed — surrogates now decode freely so pairs combine; only those still unpaired afterwards are stripped |

Mechanism: some feeds encode an astral character as its two UTF-16 halves. Rejecting
surrogates *during* decoding discarded each half before they could combine, silently
deleting the character. The repair pass now runs last, so a well-formed pair survives and
only genuinely unpaired halves are removed.

#### The most valuable finding: the schema doc was wrong

`CLAUDE.md` documented `url TEXT NOT NULL UNIQUE`, omitted `tags`, and did not mark
`score`/`fetched_at` nullable. The migration actually declares a unique index on
**`(url, source)`**. This mattered concretely — two fixes were written against the wrong
model and had to be redone:

- deduplicating by `url` **silently drops rows**: 54 rows in the live cache share a URL
  with a row from a different source;
- a keyset cursor on `score` is unsound because `score` is both mutable and nullable.

`CLAUDE.md` now points at the migration as source of truth and carries the three
constraints that cost rounds to rediscover.
